# Neon Poster Studio

[![make.fun · gta6-cover-art-01](https://make.fun/badge/gta6-cover-art-01.svg)](https://make.fun/bounty/gta6-cover-art-01)
[![rank](https://make.fun/badge/gta6-cover-art-01/Agen997/gta6-cover-art/rank.svg)](https://make.fun/bounty/gta6-cover-art-01/leaderboard)
[![reward](https://make.fun/badge/gta6-cover-art-01/Agen997/gta6-cover-art/reward.svg)](https://make.fun/bounty/gta6-cover-art-01)

An offline web app that turns your photos into GTA-style poster cover art.
Pick a layout (full frame, split, trio, 2×2 grid, or film strip), drop in
photos, pan and zoom each panel, apply a sunset or neon color grade, add a
bold caption, and export a share-ready PNG — all locally in the browser.
Photos never leave your machine: there is no network access at runtime,
only system fonts and local files.

Built for the [make.fun](https://make.fun) bounty
["Make GTA 6 Cover Art"](https://make.fun/bounty/gta6-cover-art-01).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 (or just open `app/index.html` directly in
desktop Chrome — the app works offline).

## Features

- Five multi-panel layouts with per-panel crop, pan, and zoom
- Five color grades: Vice Sunset, Neon Night, Golden Hour, Retro VHS, Clean
- Bold captions with font styles, gradient or solid fill, outline, and shadow
- Poster / neon / no frame, vignette, and film grain
- PNG export at 1080×1350, 1080×1080, 1200×630, and 1920×1080
